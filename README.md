# Apuntes de Erika

App web para subir apuntes (PDF, Word, texto o fotos), ordenarlos por asignatura y generar resúmenes y quizzes con Gemini.

- Todo se guarda en el navegador de quien la usa (IndexedDB); no hay servidor ni cuentas.
- La clave gratuita de Gemini se pega en la propia app («Conexión con Gemini») y se guarda solo en ese navegador. Nunca va en este repositorio.
- Se publica con GitHub Pages desde la rama `main`.

Clave: https://aistudio.google.com/apikey
